# OneCare

**Medical Appointment Management System**

OneCare is a web-based medical appointment management system developed as my Software Engineering final project.

The system was designed to simplify the process of finding doctors, managing availability, booking appointments, and accessing medical visit information through a clear and user-friendly interface.

## Main Features

- Search for doctors by specialization, provider, and location
- View doctor availability through an interactive calendar
- Book and cancel medical appointments
- Prevent double booking and appointments in unavailable time slots
- View upcoming and previous appointments
- Access medical visit summaries
- Doctor schedule and availability management
- Doctor appointment and patient management
- Administrative management of users, doctors, and healthcare providers
- Dedicated simplified interface for senior users
- Password reset functionality

## User Roles

### Patient
Patients can search for doctors, check availability, book or cancel appointments, manage their appointments, and view visit summaries.

### Senior
Senior users receive a simplified and accessible interface with larger and clearer controls while maintaining the main appointment-management functionality.

### Doctor
Doctors can manage their working schedule, view appointments and patient information, and create medical visit summaries.

### Administrator
Administrators can manage users, doctors, healthcare providers, and system information.

## Database

The system uses a relational MySQL database to manage users, doctors, healthcare providers, doctor schedules, appointments, visit summaries, and password reset information.

## Security

The project includes:

- Role-based access control
- Session-based authentication
- Password hashing
- Input validation
- Protected pages based on user roles
- Password reset functionality

## Project Structure

- `admin/` – Administration functionality
- `doctor/` – Doctor dashboard and management
- `patient/` – Patient functionality
- `senior/` – Senior user interface
- `config/` – Database configuration
- `includes/` – Shared components
- `assets/` – Images and interface resources

## Project Purpose

OneCare was developed to demonstrate full-stack web development, database design, authentication, role-based access, and the implementation of a complete multi-user system from planning and design through development and testing.
